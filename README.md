# Number Guessing Game

## About the Project
A beginner-level Python project in which the computer generates a random number and the user attempts to guess it.

## Features
- Random number generation
- User input
- Feedback on guesses
- Conditional logic

## Python Concepts Practiced
- Variables
- Input and output
- Random module
- Conditional statements
- Loops

## Technology Used
- Python
- Visual Studio Code

## Learning Outcome
This project helped me practise Python fundamentals, understand loops and conditional logic, and develop basic problem-solving skills.
